# Работа с сайтом КОНТУР

Перед любой правкой konturdoma.ru, включая задачи без локального клона, прочитай [общие правила](docs/site-rules/README.md), [карту блоков](docs/site-rules/blocks.md) и регламент нужного блока. Для каталога, планировок, рендеров и подбора цвета прочитай [правила каталога](docs/site-rules/popular-projects.md). Сверь текущий исходник и опубликованный блок, затем приступай к правке.

Меняй только согласованный участок. Любые новые тексты, подписи, бейджи, цены, кнопки, секции и функции требуют прямой просьбы пользователя. Сохраняй утверждённый дизайн, данные, адаптивность и поведение остальных блоков.
