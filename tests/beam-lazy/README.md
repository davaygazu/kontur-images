# КОНТУР: отложенная загрузка 3D-блока бруса

Основа: полный блок, присланный пользователем 22.10.2026 (130824). С опубликованным блоком совпадает за исключением пробелов и переносов строк.

## Изменения

- Удалено синхронное подключение Three.js из HTML.
- Версия библиотеки остаётся 0.160.0, хост jsDelivr сохранён.
- При расстоянии до секции около 600 px библиотека запрашивается асинхронно. Тяжёлая инициализация запускается в свободное время браузера с таймаутом 600 мс.
- Если пользователь успел уйти от блока во время загрузки, создание сцены откладывается до следующего приближения.
- Кадры отрисовываются только при видимой секции и открытой вкладке. После выхода из секции или скрытия вкладки RAF отменяется.
- При возвращении используется уже созданная сцена. Повторных загрузок и параллельных циклов нет.
- Сохранены геометрия, материалы, текстуры, свет, камера, тени, стили, тексты и обработчики вращения/масштабирования.
- Есть проверка дублирующего запуска, совместимый вариант без IntersectionObserver и одна повторная попытка при ошибке загрузки библиотеки.

## Установка теста

На копии страницы заменить весь существующий HTML блока «Клеёный брус» в T123 содержимым KONTUR_beam_lazy_test.txt. В HEAD ничего добавлять не нужно. Не оставлять рядом старый блок с теми же идентификаторами.

Проверить на телефоне: первый экран, появление модели при прокрутке, сборку, вращение/масштабирование, прокрутку дальше и возврат к модели. Затем сравнить несколько одинаковых запусков PageSpeed. Эффект в баллах и миллисекундах заранее не заявляется.

## Проверено

- Синтаксис всего JavaScript.
- Совпадение исходных HTML/CSS, кода создания модели и обработчиков управления.
- Автоматические проверки загрузки, её единственности, паузы, повторного запуска, скрытой вкладки, ухода во время скачивания, совместимого варианта и ограниченного повтора при ошибке.
- Реальный браузер: до приближения 0 запросов к Three.js; при приближении 1 запрос.
- В проверочном браузере WebGL отключён. Проверка отрисовки настоящей модели невозможна в этой среде.
- Для проверки остальной интеграции в служебной странице заменён только WebGLRenderer на заглушку; реальная библиотека создаёт геометрию и текстуры. Создано 6 mesh-объектов, сборка меняется от 0% до 100%, кадры идут в секции, вне неё счётчик останавливается, при возвращении цикл возобновляется без новой загрузки библиотеки.

Заглушка, счётчик и тестовая навигация отсутствуют в выдаваемом коде. Финальная визуальная проверка модели нужна на устройстве с WebGL. Рабочая страница и main этим тестом не изменены.
