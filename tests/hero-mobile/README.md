# КОНТУР: тест облегчённого главного экрана

Основа: предоставленный пользователем код главного экрана от 22.10.2026.

## Что изменено

- Только разметка фоновой фотографии: нативный picture выбирает мобильную копию при ширине до 900 px включительно.
- Мобильная копия: 1080 × 608, WebP quality 76, 144 840 байт.
- Исходник: 1672 × 941, 432 560 байт. Экономия 66,5%.
- Кадр не обрезан; цвета, оформление, тексты, ссылки, CSS, меню, фиксированная шапка и параллакс сохранены.
- Мобильный URL закреплён на ревизии с изображением. Исходный URL для компьютеров сохранён.
- Для HEAD подготовлены preconnect и мобильный preload с тем же URL и media, что в picture.

## Как проверить

1. Сделать копию страницы Tilda.
2. Заменить существующий код главного экрана в T123 содержимым KONTUR_hero_mobile_test.txt. Второй экземпляр главного экрана рядом не добавлять.
3. В настройках только тестовой страницы добавить KONTUR_hero_preload_HEAD.txt в HTML-код HEAD.
4. Опубликовать тестовую страницу. Сравнить на телефоне без VPN: скорость фотографии и её резкость; меню и появление фиксированной шапки после прокрутки.
5. Повторить Lighthouse для той же страницы и тех же условий. Сравнивать несколько запусков; записать элемент LCP и его разбивку.

## Проверки

- CSS, JavaScript, тексты и ссылки сверены с оригиналом.
- Синтаксис встроенного JavaScript проверен Node.js.
- В браузере проверены композиция на мобильной ширине, открытие/закрытие меню и выбор оригинала на компьютере.
- В новом мобильном документе проверен запрос только мобильной фотографии.

## Остальные замечания Lighthouse

- Кеш 2125 КиБ: срок задаёт HTTP-сервер каждого ресурса. Из HTML блока нельзя изменить Cache-Control файлов GitHub Raw или Tilda. Структура предупреждения с URL не предоставлена; конкретные файлы не установлены.
- Изображения 482 КиБ: этот тест уменьшает одну фотографию на 287 720 байт. Это не обещание устранить всю оценённую Lighthouse экономию.
- Блокировка отрисовки 1560 мс: на опубликованной странице найдены отдельные таблицы стилей Tilda для сетки, страницы, popup, forms, quiz и TildaSans. Без списка запросов из отчёта нельзя приписать каждому часть задержки.
- Неиспользуемые CSS 57 КиБ / JS 286 КиБ: это оценка во время конкретного запуска. Код может понадобиться при открытии квиза, формы, галереи или меню. Эти ресурсы в этом тесте не менялись.
- Минификация CSS 3 КиБ / JS 4 КиБ и legacy JS 12 КиБ: в этом тесте не исправлялись.

Подробных данных об элементе LCP и его подэтапах в предоставленном тексте отчёта нет. LCP 9,5 с нельзя целиком приписать весу главной фотографии. Уменьшение веса подтверждено; итоговую скорость и новый балл необходимо измерить после установки теста.
