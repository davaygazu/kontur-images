# КОНТУР: тест ранней загрузки TildaSans

В полный текущий блок главного экрана с konturdoma.ru добавлен только один link rel=preload для TildaSans-VF.woff2. URL совпадает с используемым в текущем fonts-tildasans.css. crossorigin=anonymous совпадает с режимом загрузки веб-шрифтов.

Фотографии, CSS, JavaScript, меню, тексты и ссылки не менялись. После нового link исходный блок сохранён буквально. Новый шрифт и новые начертания не добавлялись; font-display этим тестом не меняется.

На тестовой копии страницы полностью заменить содержимое T123 главного экрана кодом из KONTUR_hero_font_preload_test.txt. В HEAD ничего добавлять не требуется. Опубликовать, проверить мобильное меню и внешний вид, выполнить 2-3 замера PageSpeed и прислать ссылки. В других блоках и настройках ничего одновременно не менять.

Это тест устранения дополнительного ожидания обнаружения шрифта через CSS. Размещение preload в HEAD могло бы обнаружить ресурс раньше, однако этот вариант специально подготовлен для одного T123. Реальный выигрыш зависит от загрузки страницы и подлежит измерению. Блокирующие CSS Tilda в этом тесте сохраняются; улучшение до определённого балла не обещается.
