# КОНТУР - дизайн-система

Источник: экспорт Tilda от 13.10.2026, файл `page139945426body.html`. Это справочник для новых HTML-блоков, а не CSS для автоматического подключения ко всему сайту.

## Правила
- Основной фирменный зелёный: `#096041`.
- Фон основных светлых секций: `#FAFAF9`; карточки часто белые.
- Текст: `#17211e`; вторичный текст: `#69736f` (в некоторых блоках `#6d7773`).
- Шрифт: `TildaSans`, запасной `Arial, sans-serif`.
- Скругления часто 12px, но в некоторых карточках и кнопках они отличаются: повторять стили конкретного блока.
- Типичная максимальная ширина контейнера: 1200px; отступы зависят от блока и экрана.
- Адаптивные пороги различаются: 900/901px, 850px, 760px, 700px, 600px и др. Нельзя считать один breakpoint универсальным.
- Кнопки, световой блик и состояния hover не унифицированы между всеми блоками. Сверяйтесь с исходным кодом конкретного блока.
- **Не подключать все CSS-файлы ниже глобально**: это набор токенов и образцов для новых блоков; классы следует изолировать в секции.
- Внешние изображения и JS подключаются с GitHub/CDN и могут отсутствовать в архиве экспорта Tilda.

## Файлы
- `colors.css` - палитра и переменные для нового блока.
- `buttons.css` - пример фирменных кнопок, не замена всех текущих кнопок.
- `components.css` - базовые контейнеры и карточки.
- `responsive.css` - стартовые адаптивные правила, подгоняются под конкретный блок.

При правках сайта сохранять существующую геометрию, сетку, анимации и мобильную версию; менять только запрошенное. Не хранить файлы шрифтов в этом репозитории.
