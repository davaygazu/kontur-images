## Как использовать

1. На копии страницы замените содержимое соответствующего T123 нужным `.txt` целиком.
2. Не добавляйте второй экземпляр того же блока на одну страницу.
3. В HEAD ничего дополнительно добавлять не нужно.
4. Для уведомления используется один отдельный T123 внизу страницы.
5. Для объектов используйте короткий `02-projects.txt`. Не вставляйте большой JavaScript напрямую в T123. Его исходник сохранён в [sources/kontur-projects-webp-v2.js](sources/kontur-projects-webp-v2.js).
6. После восстановления проверьте на телефоне и компьютере галереи, меню, формы, отзывы, увеличение и закрытие оригиналов. Для проверки уведомления используйте новую вкладку.

## Версии и ограничения

- Фото остаются на GitHub Raw, скрипт объектов - на jsDelivr. Загрузчики сохраняют уже проверенные ссылки на конкретные коммиты.
- В основной комплект не включён вариант объектов без Ижоры: он готовился отдельно для копии сайта.
- Отзывы хранятся как лёгкий HTML, без виджета Яндекса; оригиналы загружаются только по нажатию. Исходные WebP отзывов не пережимались при доработке блока.
- По последним присланным замерам PageSpeed и PR-CY результат был 91. Это история проверок, а не гарантия балла в каждом запуске.
- Удаление или отсрочка CSS форм/квиза не выполнялись и в этот комплект не входят.
- На момент сборки в опубликованном HTML обнаружены признаки всех перечисленных доработок. Это проверка наличия функций, а не побайтовое сравнение разметки Tilda.
- `manifest.json` содержит размеры, SHA-256 сохранённых файлов и исходные коммиты. Семь новых файлов мобильных изображений добавлены в `assets/hero`, `assets/remaining-mobile` и `assets/mobile-v2`, без замены компьютерных оригиналов.

Предыдущие рабочие версии и тестовые ветки сохранены. Публикация этой папки в GitHub не меняет автоматически ни один блок Tilda.
