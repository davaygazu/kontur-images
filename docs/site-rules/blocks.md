# Карта блоков главной КОНТУР

Порядок сверён по опубликованной главной 20.11.2026. Для других страниц и новых секций действует общий регламент. Перед правкой сверяй их фактический состав, исходник и связи с главной.

| Блок в текущем порядке | Правила проверки |
| --- | --- |
| Шапка и первый экран | Сохрани логотип, пункты меню, мессенджеры и мобильную навигацию. «Проекты» в шапке ведут к каталогу. Сохрани действующий H1, подзаголовок, фоновое фото и форму по кнопке «Обсудить будущий дом». Проверь читаемость поверх фото. |
| Подход КОНТУР | Сохрани порядок преимуществ, их визуальную иерархию, действующие формулировки и действие «Обсудить проект». |
| Построенные объекты | Используй реальные фото, правильный объект, верную стадию и порядок снимков. Проверь открытие каждой обновлённой карточки, галерею и закрытие. Этот блок показывает построенные объекты и ход работ, каталог ниже показывает проекты домов. |
| Производство, история технологии и гарантия | Сверяй фотографии производства, подписи, даты и утверждённые условия гарантии. Сохраняй порядок и связь с пунктом меню «Производство». |
| Популярные проекты | Сначала прочитай [отдельные правила каталога](popular-projects.md). |
| Расчёт стоимости и квиз | Сохрани якорь расчёта, утверждённые вопросы и переходы, варианты ответа и действующую форму. Проверь шаги, счётчик, валидацию и мобильное отображение. |
| Анимация сборки бруса | Сохрани действующую геометрию деталей, порядок сборки, прогресс и поведение прокрутки. Проверь загрузку и плавность отдельно на телефоне. |
| Преимущества клеёного бруса | Сохрани порядок карточек, их заголовки и утверждённые технические утверждения. |
| Сравнение технологий | Проверь оба переключателя, «Каркас» и «Газобетон». Текст, иллюстрация и выбранная технология должны совпадать по каждой строке. |
| Отзывы | Цитату, автора, проект и оригинал сверяй попарно. Сохрани навигацию и кнопку открытия оригинала. Любая новая цитата требует источника. |
| Этапы строительства и полоса преимуществ | Проверь соответствие номера, названия, текста и иллюстрации каждого этапа. Сохрани утверждённые сроки, порядок и формулировки полосы. |
| Индивидуальный расчёт по готовому проекту | Сохрани смысл блока, изображение и действующие каналы отправки проекта. Проверь ссылки на Telegram, MAX и почту. |
| Партнёры | Сверяй написание бренда, логотип, назначение материалов и действующие ссылки. |
| Шоурум и контакты | Сверь адрес, карту, телефон, маршрут и форму записи. Проверь входящий якорь «Контакты». |
| Подвал и уведомление о cookies | Сохрани контакты, цели навигации, ссылку на политику и действующую форму обратного звонка. Проверь отображение и закрытие уведомления. |

Служебные страницы, включая политику конфиденциальности, редактируй по прямому заданию и сверяй входящие ссылки с актуальной опубликованной версией.
