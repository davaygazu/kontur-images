# Регламент сайта КОНТУР

Сайт на Tilda: https://konturdoma.ru/. Репозиторий содержит код отдельных блоков и материалы. Для каждого задания сначала найди реальный исходник нужного блока и проверь его актуальную версию в Tilda или GitHub. Если исходник недоступен, зафиксируй, что удалось проверить. Предпросмотр и опубликованная страница могут использовать разные версии.

- [Карта и правила блоков](blocks.md)
- [Популярные проекты, планировки и цвета](popular-projects.md)

## Перед правкой

1. Прочитай этот регламент и правила затронутого блока. Проверь опубликованный вид на компьютере и телефоне либо используй утверждённый снимок и текущий исходник.
2. Сохрани фирменное написание «КОНТУР», существующие шрифты, палитру, сетку, отступы, скругления и порядок секций. Стили бери из актуального блока. В новых текстах используй короткий дефис с пробелами и утверждённую терминологию.
3. Меняй только запрошенное. Подписи, заголовки, цены, преимущества, CTA и функции добавляй по прямому запросу. Факты, сроки, гарантии, комплектации и контакты бери из утверждённых материалов.
4. Сохраняй адреса страниц, якоря, привязки меню, формы, мессенджеры и аналитику в пределах их действующей логики. Изменение URL или цели кнопки требует явного задания. Новые стили ограничивай селекторами своего блока.
5. Перед передачей проверь на широком и узком экране типографику, фото, переполнение, клики, клавиатуру и затронутые переходы. Для формы проверь открытие и валидацию. Отправку тестовой заявки выполняй по согласованию.
6. Сверь изменения в Git, проверь исходники и ссылки на материалы. Если требуется код для Tilda, пришли фрагмент подключения с точным SHA и укажи, какие проверки удалось выполнить. Публикация на основном сайте выполняется по указанию пользователя.
