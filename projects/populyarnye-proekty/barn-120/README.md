# Барн 120

Памятка для блока «Популярные проекты».

- ID проекта: `barn-120`
- В попапе: «Проект дома» над заголовком «Барн 120».
- Характеристики карточки: **120 м² · 1 этаж · 3 спальни**.
- Описание: Одноэтажный дом из клеёного бруса с тремя спальнями. Кухня-гостиная 34 м² с панорамным остеклением выходит на крытую террасу. В доме также есть гардероб, постирочная, душевая, санузел и техзона.

| Помещение или зона | Площадь, м² |
|---|---:|
| Кухня-гостиная | 34 |
| Спальня 1 | 12,1 |
| Спальня 2 | 10,6 |
| Спальня 3 | 11,9 |
| Холл | 18,1 |

| Душевая | 4,8 |

| Техзона | 3,1 |

| Крыльцо слева | 6,0 |
| Крыльцо справа | 2,4 |

120 м² указаны по наружному контуру. В каталоге исходного проекта указано 112 м² внутри, на эскизе сумма подписанных внутренних зон составляет 107,7 м². Площади уточняются при проектировании. Терраса и два крыльца составляют 23,5 м².

На правом фасаде после кухни-гостиной расположена глухая дверь в постирочную. За дверью два окна спален с небольшим простенком. У бокового крыльца три прямые ступени вдоль стены.
