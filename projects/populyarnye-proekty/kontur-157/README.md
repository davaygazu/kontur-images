# Контур 157 · Памятка для «Популярных проектов»

- Название: Контур 157
- ID проекта: `kontur-157`
- Характеристики карточки: **157 м² · 2 этажа · 3 спальни**
- Внутри 157 м², по 78,5 м² на этаж. Терраса 14 м² и балкон 14 м² указаны отдельно.
- 3 спальни на втором этаже, 1 кабинет на первом, 1 санузел и 1 ванная.
- Описание: Двухэтажный дом с тремя спальнями и отдельным кабинетом. На первом этаже просторная кухня-гостиная с выходом на террасу. На втором этаже предусмотрены гардероб, ванная и балкон.

| Первый этаж | м² | Второй этаж | м² |
|---|---:|---|---:|
| Кухня-гостиная | 48,4 | Спальня 1 | 14,2 |
| Кабинет | 10,9 | Спальня 2 | 14,2 |
| Холл | 12,3 | Холл | 25,2 |
| Санузел | 3,2 | Спальня 3 | 11,9 |
| Техпомещение | 3,7 | Гардероб | 4,0 |
| | | Ванная | 9,0 |
| Терраса | 14 | Балкон | 14 |

Для попапа использовать утверждённую обложку, план двух этажей и 17 вариантов фасада. Обложка с тёмно-каштановым фасадом и чёрной боковой стеной. Тот же кадр открывать первым в попапе. Для подбора цвета использовать отдельные WebP.
